# RavMem for Antigravity

```
python3 antigravity/scripts/install_to_project.py /path/to/project    # project: .agents/ + GEMINI.md
python3 antigravity/scripts/install_to_project.py --global             # token in ~/.gemini/config/mcp_config.json
```

Project mode writes `.agents/mcp_config.json` (`serverUrl` + headers), rules, skills and scripts, and merges the
RavMem block into `GEMINI.md`. The MCP config does not read environment variables, so project mode leaves a
`YOUR_RAVMEM_TOKEN` placeholder: replace it and keep that file out of git, or use `--global`, which writes the real
token into your private user config (mode 600).

## Install as an Antigravity plugin

The repository root is an Antigravity plugin (`plugin.json`, `skills/`, `rules/`; generated by `build_content.py`):

```bash
agy plugin install https://github.com/ravmem/Ravmem-harness-plugins     # CLI
agy plugin install /path/to/Ravmem-harness-plugins                      # from a local clone
```

In the Antigravity App, use **Customizations → Marketplace → +** with the same repository URL, or copy the folder to
`~/.gemini/config/plugins/ravmem`. The plugin adds the seven RavMem skills, including the user-invoked `/ravmem-setup`
and `/ravmem-configure`. It deliberately **does not bundle the MCP connection**, so your token lives in your own
`~/.gemini/config/mcp_config.json` and survives plugin updates: run `/ravmem-setup` to install a server, then
`/ravmem-configure` to add the connection entry.

Notes from testing with `agy` 1.2.12:
- Install from the repository URL as shown. Antigravity also understands Claude Code plugin layouts; because the root has a
  `plugin.json` it uses this one, but a Claude Code install would give you an empty MCP entry and unresolved options.
- The plugin name is `ravmem`, so installing it **replaces** any plugin already installed under that name (for example an
  older RavMem plugin). Check `agy plugin list` first.
- Plugin `rules/` were listed but not applied to the model in `agy -p` (project-level `.agents/rules` were). Skills work. For
  always-on rules, use the project installer below.
- Hooks are not shipped: Antigravity has no session-start hook, so memory is loaded by the skills and rules instead.

## Install the server

The user-invoked `ravmem-setup` skill guides you through writing the compose file and a sample `.env`, starting the stack and activating the license with the RavMem CLI; `ravmem-configure` then connects Antigravity to it. See the repository README, "Installing the server".
